# 历史归档

本目录保存 2026-08-22 文档治理重构前的材料。内容仅用于追溯，不再更新，也不构成当前产品或开发契约。

| 目录 | 内容 | 当前替代来源 |
|---|---|---|
| `contracts/` | 早期并行实现合同 | 开发者指南与生成的公共 schema |
| `spec/` | 数据库、计算、任务、注册表旧规格 | 架构宪法、领域模型与公共契约 |
| `roadmaps/` | 旧“产品版本 2”路线图 | `manual/changelog/roadmap.md` |
| `design-input/` | 早期 RPD 设计输入 | 正式文档三入口 |
| `workflows/` | 历史 agent 工作流 | 当前贡献规范 |
| `brand/` | 品牌提案与预览 | 产品现有品牌资产 |
| `adr/` | 已批准并完成正式规范落地的架构决策；代码迁移状态以 Roadmap 为准 | 架构宪法与对应正式章节 |

如果归档与现行文档或代码冲突，以[架构宪法](../../manual/developer-guide/zh-CN/ARCHITECTURE_CONSTITUTION.md)规定的效力顺序裁决。
