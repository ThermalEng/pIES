# ADR-0008：取消画布人工验收例外

> 状态：用户已批准、指导文件已实施、已归档
> 决策及归档日期：2026-10-12
> 批准依据：用户明确要求取消指导文件中的拖动图人工检查说明
> 归档原因：现行规则已纳入架构宪法 §14.3 与前端指南
> 现行替代来源：架构宪法 `1.12.3` §14.3、前端与帮助中心指南
> 替代决策：ADR-0002；其历史正文及既有验收证据不改写

## 决策与影响

画布拖放与接口连接不再要求人工核查，也不再禁止 Playwright；与其他 GUI 功能一样在 Docker 中通过真实浏览器交互验收。该例外在多个指导文件重复，会使 agent 按旧规则跳过自动验收，因此同步取消所有现行说明。只删除个别文件的表述会留下相互冲突的执行规则，不予采用。

业务代码、数据契约和权限均不变，无数据迁移；测试按受影响用户流程推进，不通过状态注入替代拖放或连线，也不因本次文档修改宣称已有验收通过。若需撤销该决定，应再次获得用户批准并同步修订现行规则，不恢复隐含例外。
