# ADR-0002：画布拖放采用人工验收

> 状态：已批准、已实施、已归档  
> 决策日期：2026-08-22  
> 批准依据：仓库 AGENTS.md 明确约束  
> 修订条款：架构宪法第 14.5 节

## 问题

画布拖放与端口连接高度依赖坐标、缩放、视口和人工可见语义。仓库规则要求该功能由人工核查，与原宪法要求所有动作使用 Playwright 的表述冲突。

## 决策

画布拖放和端口连接由人工执行并记录可见结果。画布参数编辑、导航、校验和错误展示等非拖放功能继续使用 Playwright。HTTP 和模块测试仍覆盖真实端口、方向、载能和装配规则。

## 影响

发布清单必须单列人工画布验收证据。自动测试不得声称替代拖放核查，也不得通过修改页面状态绕过其他浏览器流程。
