# ADR-0013 Worker 尝试生命周期与内置求解器

> 状态：用户批准
> 日期：2026-11-21
> 适用范围：Worker、任务持久化与内置求解执行
> 所有者：pIES 项目
> 上游依据：用户批准的防御性措施清理切片 1
> 规范正文：[架构宪法](../../../manual/developer-guide/zh-CN/ARCHITECTURE_CONSTITUTION.md)

原 60 秒租期将短时控制面停顿等同于失去执行资格。延长租期仍会在更长中断时终止正常任务，并推迟真正退出的回收。改为显式收拢，保留并发槽和尝试 token。控制面断连时继续求解，写入等待数据库恢复。任务进程退出由监督进程收拢，整机退出由管理员解锁恢复。

计算 Worker 启动时检查内置 HiGHS 的版本和可用性。内置执行器使用参数数组，记录声明输出文件大小并分块封存。表达式保留 AST 白名单，原型 runner 未接入生产，用户插件仍适用独立隔离部署规则。

开发数据库按当前模型从空库初始化。前后端活动租约 DTO 同步移除续租和到期字段。回归覆盖短时断连、进程退出、取消与超时。回滚恢复本次改动及相应数据库备份。
