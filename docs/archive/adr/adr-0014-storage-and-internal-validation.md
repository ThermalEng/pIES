# ADR-0014 对象清理与内部校验

> 状态：用户批准
> 日期：2026-11-21
> 适用范围：存储、上传、证据提交及持久化
> 所有者：pIES 项目
> 上游依据：用户批准的防御性措施清理切片 2
> 规范正文：[架构宪法](../../../manual/developer-guide/zh-CN/ARCHITECTURE_CONSTITUTION.md)

容量估算和固定阈值会拦截可成功的任务；健康接口抽样读取内容会使管理请求承担对象大小的内存成本。改为按真实写入结果报告，健康读取元数据。管理员可预览孤儿对象并直接清理，引用和明确业务保留规则继续生效。缩短软删保留期仍需维护中间状态和恢复接口，因而采用一次清理操作。

同步更新管理契约并从当前 schema 初始化开发库。上传继续封顶读取并校验领域输入，结果可以在生产 Worker 通道下发布与读取。数据库触发器继续保护不可变表。回滚恢复对应代码和数据库备份。已物理清理的对象通过部署备份恢复。
