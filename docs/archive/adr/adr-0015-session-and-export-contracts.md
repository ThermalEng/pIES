# ADR-0015 会话、管理操作与导出

> 状态：用户批准
> 日期：2026-11-21
> 适用范围：认证、项目管理、任务管理、导出
> 所有者：pIES 项目
> 上游依据：用户批准的防御性措施清理切片 3
> 规范正文：[架构宪法](../../../manual/developer-guide/zh-CN/ARCHITECTURE_CONSTITUTION.md)

允许同账号独立会话，保留账号授权、密码哈希、令牌哈希和会话时效。旧窗口接管与登录前置限流增加会话中间态并影响多窗口操作。管理员删除账号通过界面预览范围；项目删除通过普通确认；任务解锁由管理员权限和任务状态控制。

导出按当前项目权限和对象引用查找并下载。延长签名令牌仍会复制授予权限的依据，因此移除令牌和到期状态。浏览器入口继续使用 CORS 与 HttpOnly、SameSite=Lax 会话 Cookie。

前后端同步更换 DTO、移除旧路由。开发库按当前表定义初始化。浏览器测试覆盖同时登录、删除与下载，后端回归验证权限和对象归属。回滚恢复代码与部署数据库备份，客户端随同版本切换。
