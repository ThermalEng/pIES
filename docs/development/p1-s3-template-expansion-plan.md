## 1. 交付范围

S2 已交付完整关系集合和现有统一分析入口。S3 在此基础上复用技术方程及逐步规划约束的编译结构，分块绑定实际系数、分配行列并生成同源结果引用。生产 `generate` 必须实际使用该路径。

本轮减少重复遍历和临时对象，不减少运行决策数量。全运营期仍是完整时域，规划容量为全期共用标量，各步运行变量保持独立；月份、年份和税务期间仍按冻结输入解释。

不引入年份压缩、典型期近似、跨任务缓存、新界传播、建设激活或网络新语义。S4 负责来源持久化与集成收口；本轮沿用内部来源链及现有公开诊断、Bundle 和适配器协议。需要公开变化时先提交主审裁决。

## 2. 基线与关键路径

本基线的主要重复工作是：`_build_relations` 按步复制符号表、装入该步预定义值，再经 `lower_relation` 遍历原技术 AST；逐步规划约束已保留编译模板，但仍逐步组装映射和仿射行。已有序列 SI 缓存继续使用，不能把它描述为本轮新优化，也不能声称旧链每步重新解析 YAML。

```text
S2：收齐关系、统一绑定与分析
  ↓
按关系结构及符号角色编译模板
  ├─ 符号槽：规划标量／当前步／前一步
  ├─ 系数计划：常量／实例参数／实际输入序列
  └─ 条件操作：保持已有互斥与零界特化
  ↓
按实际步或期间绑定，分块分配行列
  ↓
原 LinearModel 与同次解声明 → MPS／元数据／Bundle
```

关键路径：**已收集关系 → 可复用结构 → 实际步系数与全局索引 → 稀疏行列及同源输出 → 等价与资源对照**。分块是内部构建方式，不是新的业务时域。

## 3. 实现要求

### 3.1 模板保留结构，实例绑定保留事实

- 从 modeling 已解析 AST 和 S2 已编译规划结构构造模板，不再发明公式语言或把表达式重新拼成字符串执行。
- 区分固定参数、已知序列和决策量。模板保存系数的来源与运算结构；逐步读取该步已知量，不把第 0 步数值复制到后续。
- 固定容量与规划接管容量使用各自正确的绑定模式；同模型不同实例可以共享相容结构，不共享参数值、来源归属或实例输出列。单次构模内复用即可，不增加内容 hash 或全局注册表。
- 结构编译次数随有效关系结构／绑定模式增长，不随时域点数逐步重复；实例化次数及最终矩阵规模仍可随点数增长。
- 保留现有单关系降级公开入口及其行为，复用同一编译／绑定原语；不保留旧项目构模器作为运行期 fallback，也不新增快慢模式业务开关。

### 3.2 逐步系数与条件变化

例如 `output[t] = capacity * input[t]`：模板保留 output 当前步槽、capacity 标量槽以及 input 的实际步系数。已知量相乘／相除属于系数求值；未知量乘未知量继续遵守现有能力边界。

- 系数由零变非零或改变符号时，只处理该步，不删整个关系族，也不沿用首步的区间方向。
- 后续步出现零除数等实际系数求值失败时，通过已有失败链保留关系、实例及实际 step，不按首步合法性掩盖后续失败。
- 互斥使用 S2 的统一界入口和现有精确转换；恒零与非退化场景按实际绑定条件处理。不得为复用模板交换因子极性、删除约束、猜有限界或扩大语言能力。

### 3.3 分块展开与状态连接

- 行列按确定性规则分配，避免每行重建全实例符号字典，避免另存一套全展开中间 AST／系数模型后再复制到最终模型。可以保留最终 `LinearModel` 的全时域行列；本轮不要求重建 writer 或改磁盘协议。
- 内部块大小不成为用户输入或业务参数。按测量选择实现；用不同内部块大小验证数学含义不变。
- `t=0` 的前序状态只替换为冻结初值表达式；依赖规划量的仿射初值保持该决策引用。非首步继续引用全局 `t-1`，包括块首、月首和年首。
- 不新增终期 SOC、年末闭合或块间重置。VAT 留抵、亏损批次及发生年现金流保持 S2 期间连接，不按运行块重复确认费用或税额。
- 各步实际列分配与 `unit_map`、`step_series`、`components`、`financial_facts` 保持同源；适配器不拆列名、不重建模型。取消／隔离检查覆盖模板编译及各块展开，不发布半份 Bundle。

## 4. 建议推进顺序

| 步骤 | 实现内容 | 检查点 |
| --- | --- | --- |
| A：固定对照 | 复用 S2 的公开合成输入和测量入口，记录重复编译、符号复制及阶段开销 | 对照基线为本计划给出的 S2，不把本轮代码输出的旧标签当作修改前测量 |
| B：模板与系数绑定 | 技术 AST 编译一次，保留符号槽、系数计划、初值与已有条件操作 | 固定／规划容量、不同实例、零值、符号变化及后续步失败正确 |
| C：生产分块接入 | 统一技术及逐步约束展开、索引分配与输出引用，保留 S2 收集屏障和界分析 | `generate` 实际消费模板；跨块状态和确定性保持；删除被替代的逐步重复构模路径 |
| D：集成对照 | 定向真实求解、Adapter 恢复、协作停止及多规模资源测量 | 给出数学等价证据、实际资源改善和剩余瓶颈，不进入 S4 或 P2 |

四步在本 S3 PR 内完成，可分提交。不为了完成本轮去重写税务算法、对象存储、Runtime 或前端；既有领域操作只做接入所必需的调整。

## 5. 验收与测量

### 正确性

| 性质 | 最小验收内容 |
| --- | --- |
| 结构复用 | 同一关系增加时步时结构编译次数不线性增加；生产入口真实使用，不只在模板单元测试调用 |
| 实例与单位 | 同模型两实例不同参数；固定／规划容量；等价业务单位；共用规划标量而不共用各步运行决策 |
| 时变系数 | 非常数出力／负荷／电价，零值与符号变化；合法初步后发生的零除数可定位；不改变既有非仿射拒绝 |
| 状态与分块 | 首步仿射初值、块首 `t-1`、跨月跨年连续状态；块大小改变不改变问题；不引入年末重置 |
| 条件与财务 | 既有零界和有限界互斥、月峰、VAT 留抵/退款、所得税亏损、初建/换新折旧及净收付仍与同次解对账 |
| 输出与生命周期 | 相同输入和版本重复生成确定字节；技术序列／财务输出引用实际列；公开辅助入口仍可独立调用；构模停止不发布半成品 |

以小型合成模型验证行系数、目标、可行性及真实 HiGHS 主解；允许多最优曲线不同。完整公开 provider 仍走合法运营年限，少量步的内部单元测试不冒充完整生成验收。不要新增生产端求解后重复复核。

按影响复用现有 `test_linear_lowering.py`、`test_project_model.py`、`test_battery_planning.py`、`test_step_relations_s2.py`、`test_p1_compiler_s1.py`、`test_p1_s2_relation_analysis.py`、`test_issue04_d2.py`、`test_finance_s2_execution.py` 及 VAT／所得税、生成器停止与真实结果恢复测试。检查定向选择器，尤其保证修改模板／共享构模入口时会选到线性降级、项目模型和月需量消费者，不要求无关提交全量执行。

### 资源对照

- 至少包括短模板用例、原公开 campus 单年，以及合法的跨年／多实例合成规模；沿同一镜像、资源限制和测量方式对照 S2。较大规模只构模测量，小规模承担真实求解正确性。
- 记录结构编译次数、绑定／实例化次数、变量／行／整数／非零数、MPS 和元数据体积，以及收集／分析、模板编译／展开、MPS、元数据／Bundle 的时间和峰值内存。不能低成本拆分的阶段标明合并范围；实际物化、求解和恢复开销单列。
- 修改前后在同一 CI 环境做可重复对照，区分追踪开销、进程累计 RSS 与独立阶段峰值；测量数据放测试产物或 PR 评论，不写入确定性 Bundle。
- 证明重复结构编译和临时对象实际减少，并报告端到端构模耗时／内存变化。仅改变方法名或单项计时下降不足以宣称提速；最终矩阵、writer 或元数据仍占用的成本如实报告。
- 不预设任意机器的秒数门槛，不要求矩阵体积因模板复用而减小；行列、整数数量或数值变化必须说明来源并验证等价性。不得通过缩小时域、改模板上限、减测试断言或增加默认边界取得“改善”。
