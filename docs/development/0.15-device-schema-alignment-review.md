- application 按本项目草稿/版本的精确模型引用读取，通过 model/storage/devices 公开能力组合。selector、命令入口、装配及冻结所见须为同一项目作用域描述；不把数据库元数据列表强转为 descriptor，也不把模型注册进进程全局目录。
- 共享必要的项目作用域解析代码，不在三处分别维护新注册表或重复查找框架；不复制模型正文成为第二权威源。确需扩展装配公开入参时只传本用例已准备的不可变值，装配不访问 DB/storage。

- Docker 定向覆盖作用域、装配/冻结实际模型身份与关键参数；Playwright 从保存成功开始真实选择项目模型、拖放、连线、参数编辑、提交和查看结果，核对可手算的关键求解值，不只验证 completed。保留原目录设备的必要邻接检查，不重跑全仓。
