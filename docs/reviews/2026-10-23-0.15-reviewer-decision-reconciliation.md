日期：2026-10-23。审查基线：`b5411bb`；在线开发快照：`15daecf`。
性质：用户批准公开的脱敏交接，不是产品规范、完整案例参数台账或收益验收结论。

本文件仅保留决策状态和后续处理边界。案例身份、原始文件、具体数值、输入序列、内部决策编号、私有路径及参考结果均不包含在本交接中。公开副本不能用于重建盲测输入；需要实际参数时，由用户或资料保管者另行提供授权信息。

## 已确认的事项：不重新讨论原则

| 类别 | 已确认状态 | 后续处理 |
| --- | --- | --- |
| 核算边界 | 不同业务场景的核算视角已有确认 | 核实界面和财务模型能否表达，不把入口缺失解释为用户尚未决定核算主体 |
| 基础数据 | 数据选择、修正与校准口径、时间分辨率已有确认 | 按已授权的确认记录使用；不凭文件表面差异重新选择数据或擅自缩放 |
| 物理边界 | 设备容量基准、并网／受电边界和运行时长等已有确认 | 不由程序默认值或测试脚本代选，也不将具体场景参数固化为程序规则 |
| 财务评价 | 折现率和建设付款原则已有确认 | 缺少具体记录时明确说明信息缺失，不重新讨论已确认原则，不自动均摊或另设建设年份决策 |
| 通用能力 | 月最大需量计费、规模关联年度维护已获批准 | 属于待实现的产品能力，不再要求用户重复批准功能方向；字段与方法仍以正式契约为准 |
| 维护与税务 | 维护现金支出的报告分类与税务处理分别确定 | 不因费用名称自动推导当期全部可扣，也不重复计入现金流或扣税 |

## 尚需核实的细节：不是新的功能需求

| 类别 | 需核实内容 | 处理边界 |
| --- | --- | --- |
| 增值税与抵扣 | 实际纳税资格、票据取得能力、可抵扣费用构成 | 公开研究建议不等于项目事实，不擅自认定资格或形成程序默认税率 |
| 所得税 | 实际税率、优惠资格及适用年度 | 未确认优惠不等于优惠已获准，也不等于可以改写已确认的其他参数 |
| 资产与期末处理 | 计税折旧、更换支出的税务归属、期末现金回收假设 | 区分税务残值与实际回收现金，确认后固定到本次计算输入 |
| 付款时点 | 已确认付款原则与财务时轴的具体对应位置 | 只核实剩余落点，不重新设计付款策略或自动平均分配 |
| 周期与日历 | 周期输入用于自然年时，月份及闰日映射是否已有进一步确认 | 先查最新确认；仍缺时说明最小待选事项，不擅自插值、复制或平移 |

## 在线接续时怎样使用本记录

1. 先核对用户最新确认与当前正式规范。旧记录仍标注待定，不足以推翻较新的明确确认。
2. 找不到已确认的具体值时，说明缺少哪份输入或哪项值，由资料保管者补充；不重新询问整个业务原则，也不猜值。
3. 产品缺口与业务参数核实分开推进。缺少规划配置、成本或计量绑定入口，应修复产品入口，不要求用户用后台请求代替正常操作。
4. 模拟用户继续从真实需求出发发现使用问题；主审核实、去重和裁决后再派工。合成测试证明通用能力，不证明真实案例收益正确。
5. 未能执行的求解、现金流、评估和导出仍记为未验证，不从接口存在或局部成功推导完整通过。
