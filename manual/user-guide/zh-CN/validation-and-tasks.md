# 校验与任务

## 运行项目校验

1. 打开工作台“校验”。
2. 点击“运行校验”。
3. 等待模型、数据、计算配置、财务基准和运行条件全部检查完成。

结果可能是“通过”“存在警告”或“存在阻断问题”。阻断问题会禁止提交任务；警告不一定阻断，但应逐项确认。

## 确认财务基准

财务基准确认是一次审计记录（确认人、确认时间与当时假设字典），不是“基准方案双重求解”，也不产生评价参数：真正的评价参数只来自提交任务对话框中的类型化评价确认块（建设期/运营年限/付款/维护/折现率）。当前页面确认按钮处于暂停状态，确认经后端 `baseline-confirm` 接口记录（提交预检门禁要求已有确认记录）；恢复页面入口前请沿用现有调用方式。确认记录不可被新确认覆盖。

## 提交任务

提交前先在计算配置页保存配置：打开“提交任务”对话框会展示
将要引用的配置 revision（例如“引用已保存配置 revision v1”）；
未保存时提交按钮保持禁用，提交时先运行项目校验，存在阻断问题
同样禁止提交。提交后任务快照冻结该 revision 的配置正文，
后续再改配置不影响已提交任务；在任务详情可查看快照所用的配置
revision。既有任务的列表查看、取消、重试不受影响。

1. 打开“任务中心”，点击“提交任务”。
2. 选择任务类型（计算 / 规划优化 / 不确定性分析 / 批量分析）。
3. 在“评价确认”栏填写建设期（非负整数年）、运营年限（正整数年）、折现率（0..1 之间的小数，如 0.08）、建设付款比例（JSON，比例合计为 1）与维护/换新清单（JSON，逐项写发生年/金额/币种，可为空数组）。评价年限 E=K+N 由前两项自动派生并展示，不需手填。各项提交时必填、无默认值，留空会被拒绝而不会按 0 处理。
4. 核对配置摘要、数据集与任务参数后点击“提交任务”。提交后建设期、运营年限、付款、维护与折现率连同确认人、确认时间冻结进任务快照，后续改动不影响已提交任务；在任务详情可查看快照所用的配置 revision。

每次打开对话框提交都是一次新的逻辑提交：相同输入已有未结束任务时会先提示，由你确认是否继续；同一对话框内因网络失败重试不会产生重复任务。输入改变后应提交新任务，不要依赖旧任务复用。

## 查看进度与详情

任务列表显示类型、状态、进度、创建时间和发起人。点击一行查看详情，包括当前阶段、尝试次数、计算快照和用户可见诊断。

- 排队中或运行中的任务可以取消；
- 失败、超时或已取消的任务可以重试；
- 重试沿用同一份计算输入，不代表重新读取当前草稿；
- 完成且有结果的任务会显示“查看结果”。

技术状态与业务结局不同：“已完成”表示任务正常结束，但业务结局仍可能是“无推荐方案”“多目标无可行解”“结果受限”或“证据不足”。

## 任务失败时

1. 打开任务详情，先读“业务说明”和“诊断信息”。
2. 按“定位”和“修复建议”回到模型、数据或配置页面处理。
3. 重新运行项目校验。
4. 输入已改变时提交新任务；只有临时故障且输入不变时才使用“重试任务”。
