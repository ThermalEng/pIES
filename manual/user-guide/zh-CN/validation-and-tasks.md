# 校验与任务

## 运行项目校验

1. 打开工作台“校验”。
2. 点击“运行校验”。
3. 等待模型、数据、计算配置、财务基准和运行条件全部检查完成。

结果可能是“通过”“存在警告”或“存在阻断问题”。阻断问题会禁止提交任务；警告不一定阻断，但应逐项确认。

## 确认财务基准

财务基准表示“不新增建设、只使用已有设备运行”的对比方案。核对模型与经济参数后点击“确认财务基准”。确认记录会保留确认人、时间和当时假设，不能用新的确认覆盖旧记录。

## 提交任务

提交前先在计算配置页保存配置：打开“提交任务”对话框会展示
将要引用的配置 revision（例如“引用已保存配置 revision v1”）；
未保存时提交按钮保持禁用，提交时先运行项目校验，存在阻断问题
同样禁止提交。提交后任务快照冻结该 revision 的配置正文，
后续再改配置不影响已提交任务；在任务详情可查看快照所用的配置
revision。既有任务的列表查看、取消、重试不受影响。

1. 打开“任务中心”，点击“提交任务”。
2. 选择任务类型（计算 / 规划优化 / 不确定性分析 / 批量分析）。
3. 核对配置摘要、数据集与任务参数后点击“提交任务”。

## 查看进度与详情

任务列表显示类型、状态、进度、创建时间和发起人。点击一行查看详情，包括当前阶段、尝试次数、计算快照和用户可见诊断。

- 排队中或运行中的任务可以取消；
- 失败、超时或已取消的任务可以重试；
- 重试沿用同一份计算输入，不代表重新读取当前草稿；
- 完成且有结果的任务会显示“查看结果”。

技术状态与业务结局不同：“已完成”表示任务正常结束，但业务结局仍可能是“无推荐方案”“多目标无可行解”“结果受限”或“证据不足”。

## 任务失败时

1. 打开任务详情，先读“业务说明”和“诊断信息”。
2. 按“定位”和“修复建议”回到模型、数据或配置页面处理。
3. 重新运行项目校验。
4. 输入已改变时提交新任务；只有临时故障且输入不变时才使用“重试任务”。
