# 计算配置

计算配置相关页面（包含“财务配置”、“成本与计费绑定”、“规划配置”与“计算配置”）共同完成经济规则、优化目标、约束条件与求解选项的设置。各项配置每次保存都会生成不可变修订版本（Revision），确保后续任务提交时能够精确追溯。

---

## 一、配置项目财务

在工作台打开“财务配置”，管理地区财务基准（财务画像）、项目覆写与最终生效的“有效财务配置”：

1. **选择或登记财务画像**：在已有画像列表中选择并点击“引用/切换”；或准备符合[财务 YAML 契约](../../developer-guide/zh-CN/formats/finance-yaml.md)的完整文档粘贴至“财务画像文档”，按需在下方结构化编辑区增改需量费项后点击“登记”并引用到项目。
2. **项目覆盖（可选）**：如需微调当前项目的设备单价、能源价格或需量费率，可在“项目覆盖”中填写稀疏覆盖文档或通过结构化编辑区调整并保存；点击“清空覆盖”或“沿用画像”可撤销覆盖。
3. **核对有效财务配置**：在只读视图中核对合并后的成本、能源价格、需量费与税务参数。*(注：若修改了财务配置，请重新检查并保存下文的“规划配置”，使规划绑定同步失效校验。)*

### 年度费用、换新折旧与净回收

通过财务完整文档可直接配置以下项目级经济关系，无需寻找专用表单：

- **常年固定运维（`annual_fixed_om`）**：固定年费（如 `CNY/a`）与按容量等规模计取的年费；按实际运行量计费的使用运维费在 `period_variable_om` 独立配置；
- **换新折旧与费用扣除**：大修或换新支出在“提交任务”的维护清单填写；若需资本化折旧，在所得税规则的 `depreciation` 中以 `base_from` 引用初建成本或对应评价年的维护项序号（`first_year` 填写自投产起的运营年序号，与维护支付所用的评价年区分；资本化项目不再同时设为当期费用扣除）；
- **期末净回收或额外净现金（`net_cashflows`）**：显式填写时点、流入/流出方向与固定金额或来源比例（计税残值不会自动转化为现金回收）；
- **选建与发生条件**：需随某个设备建设单元开关同步触发的固定成本，请在装配的 `cost_occurrence` 中明确关联建设单元（参见[费用发生条件](../../developer-guide/zh-CN/formats/assembly-yaml.md#费用发生条件)）；
- **命名费用与金额约束**：需要针对同一规模拆分多笔独立税率费用、自定义收付发生或资产组合时，可使用财务文档中的 `items`、`amounts`、`cash_movements`、`assets` 扩展节（写法见[命名金额、支付与资产](../../developer-guide/zh-CN/formats/finance-relations.md)），并在“规划配置”的完整文档通过 `amount_relation` 施加预算或金额约束（参见[金额引用约束](../../developer-guide/zh-CN/formats/assembly-yaml.md#金额引用约束)）。

### 按月份配置日价格曲线

适用于不同自然月沿用各自典型日价格曲线的场景（若各年价格不同，请使用全期价格序列）：

1. 在“数据管理”上传完整一天的价格 CSV 文件并复制“价格对象 ID”（详见[价格序列文件](data-preparation.md#价格序列文件)）。
2. 在“财务配置”的画像或项目覆盖中定位目标能源价格条目，将“价格来源”切换为“按月份选择日曲线”。
3. 设置分辨率与价格单位，为 1—12 月分别填入价格对象 ID（可先填一月后点击“全部月份引用一月曲线”批量填充，再单独替换特定月份）。
4. 登记画像或保存项目覆盖，确认有效财务配置更新后重新保存规划配置。

## 二、设备成本与计费绑定

在“成本与计费绑定”页面中，将项目设备实例与财务配置中的类别及能源价格关联（保存至当前装配草稿）：

1. **设备实例成本归属**：为画布中的每一个设备实例显式选择“无设备成本（`none`）”或“计入设备成本（`costed`）”。选择 `costed` 时，选择对应的 `finance_type`，并把所需的每个 `driver` 映射到该实例的技术属性或接口（时序接口须选定积分 `integrate_positive` 或累计 `sum_positive`）。*(无设备成本的纯计量节点仍可参与下方能源与需量计费。)*
2. **能源购售计费点（可选）**：按需要添加计费点，指定唯一计费标识、所引用的价格条目（买/卖会计方向由价格本身决定，不依赖接口的物理方向名称）、计量设备、单向时序接口及聚合方式；无需电价计费时可留空。
3. **自然月最大需量计量绑定（可选）**：填写唯一计费点标识并绑定需量费项、受电设备及电力输出功率接口；未配置时不会产生需量账单。
4. 点击“保存成本与计费绑定”。注意草稿保存成功仅代表关系已记录，具体引用、量纲与完整性将在“校验”页做权威检查。

## 三、规划配置与系统技术方程

1. **规划目标**：选择最大化或最小化并填写目标表达式；执行税后净现值优化时，选择最大化并填入 `system.after_tax_npv`。
2. **规划变量**：逐项添加需要优化的容量或参数变量，填写变量名、选择设备实例及技术参数，并按需填入上下界十进制数值（留空表示不设该侧项目边界，不自动补零或设默认值）。
3. **规划约束与逐步关系**：需要额外经济或技术限制时可添加约束；若需编写跨实例的逐步端口约束（`step_relation`）或金额约束（`amount_relation`），可切换至“完整 YAML 文档”编辑（格式见[逐步技术约束](../../developer-guide/zh-CN/formats/assembly-yaml.md#逐步技术约束)），系统会自动保留表单未展开的合法字段。
4. **系统技术方程（可选）**：如需声明跨设备能量分配、来源账户或输出系统辅助序列，可在“系统技术方程”编辑器填写 `system_equations` 与 `outputs` 片段并保存至草稿（参见[网络边界与系统方程](../../developer-guide/zh-CN/formats/network-relations.md)）。
5. 点击“保存规划配置”生成新修订号。

## 四、计算配置（求解器与算法选项）

打开“计算配置”页设置本次求解的执行方案（**本页不包含评价年限或折现率**，这些参数在提交任务时确认）：

| 字段 | 填写说明 |
|---|---|
| 计算模式 | 例如 `planning` |
| 生成器与求解器 | 选择或填写精确版本引用（如 `ies.generator.highs_milp@1.0.0` 与 `ies.solver.highs@1.7.2`） |
| 计算精度 | 必选：`low`、`medium` 或 `high`（无默认选择） |
| 时间限制（秒） | 求解器内部运行上限（新建项目默认按部署配置初值填入） |
| 随机种子 | 可留空或填整数 |
| 输出请求 | 必填 JSON 数组（如 `["solution", "metrics"]`） |
| 预测配置与收敛 | 配置 `data_predict` 接口所用预测算法与参数；仅当包含耦合预测算法时填写 `{"tolerance": ..., "max_iterations": ...}`（最大轮数至少为 2），否则留空 |
| 生成/求解选项 | 可选 JSON 对象，须符合所选生成器选项规范 |

填写完成后点击“保存计算配置”，界面会显示当前最新修订号（例如 `v1`）。如遇到他人先保存造成的版本冲突（`409`），页面会保留你正在编辑的内容，可按需选择“重新加载最新配置”或修改后重新保存。若计算配置尚未保存，后续项目校验将会提示阻断错误，且无法提交计算任务。

下一步阅读[校验与任务](validation-and-tasks.md)。
