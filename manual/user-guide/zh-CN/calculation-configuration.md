# 计算配置

计算配置页保存项目唯一的计算配置全文。后端按不可变 revision
存放，每次保存产生一个新 revision；页面只读写最新 revision。

## 开始之前

先完成系统建模。计算配置不包含评价周期、折现率等财务假设，
也不包含内部收益率约束，这些不在本页填写。


## 规划配置（ISSUE-05）

工作台现在单独提供“规划配置”入口，与本页的计算配置不同。规划配置
通过 `GET/PUT /api/projects/{id}/planning-config` 维护独立的不可变
revision。首次保存前必须先在“财务配置”中引用地区画像并生成有效财务
快照；财务配置发生变化后必须重新检查并保存规划，旧 revision 不会
自动更新或偷偷沿用。

1. 在“规划配置”选择目标方向（最小化/最大化）并填写公开受限表达式。
   税后规划目标的正式表达式为 `system.after_tax_npv`，须明确选择最大化；
   不会自动从财务画像或设备类型推断规划目标。
2. 添加至少一个规划变量，分别填写唯一变量名、已建模的设备实例名、
   真实技术参数名以及可选容量下界、上界和单位。边界填十进制原文，
   空值表示未显式设置该侧界，禁止以零或猜测容量替代。
3. 需要额外约束时逐项填写唯一名称、公开约束类型、受限表达式、
   启用状态。没有额外约束时可保留空约束集，系统本身的设备/能流
   物理约束仍按正式装配规则生效。
4. 点击“保存规划配置”，确认显示 revision 编号。刷新重开页面时
   应读回原值；发生并发冲突（409）时保留未提交编辑，由用户决定
   是否主动重载最新 revision，重载会丢弃未保存编辑。
5. 表单只负责用户必要字段的最小检查，服务端仍会对目标表达式、
   同实例同参数变量、引用和公开领域规则做正式校验；错误直接显示，
   不自动修复或绕开任务门禁。

规划入口完成并不表示任务必然可提交：项目还需补齐实例成本与计量
绑定（ISSUE-03）、数据与评价确认等正式必需输入。实际任务快照必须
引用被接受的规划配置 revision，不允许通过 API 测试前置冒充 GUI 完成。

## 设备成本与计费绑定（ISSUE-03）

工作台“成本与计费绑定”是**装配草稿**的编辑入口，与财务画像／项目覆盖
和规划配置均独立。使用前先在“系统建模”中建立真实设备实例，并在
“财务配置”中明确引用画像、生成有效财务快照。

1. 对每一个设备实例，在“设备实例成本归属”选择“无设备成本
   (type: none)”或“计入设备成本 (type: costed)”。未选择的实例不得
   保存；系统不根据设备名称、技术类型或载体推断成本归属。“无设备
   成本”的纯计量设备仍可承担下方的购售计费。
2. 选择 costed 时，手动选择有效财务快照已声明的 `finance_type`，
   并逐项把其实际被消费的 `driver` 绑定到该实例的技术属性或接口。
   属性不填写聚合，接口必须选择 `integrate_positive` 或
   `sum_positive`。页面只列出公开设备参数、接口和财务 driver 作为
   参考，不自动选取或补齐；按存量/新增、成本分量和单位量纲的进一步
   判定仍由装配正式校验负责。
3. “能源购售计费点”可以明确保留空表，或者添加
   `binding_id → {price, instance, interface, aggregation}`。价格从
   有效财务快照 `energy_prices` 中选取，使用者明确指定计量实例、
   可计量接口及聚合。计费方向与载体只取价格条目原始声明，不根据
   价格键名推断，也不自动用设备成本绑定代替计量关系。
4. 如需按月最大需量计取容量电费，在“自然月最大需量计量绑定”添加绑定，填写唯一计费点标识，选择
   已登记的需量费项、计量设备实例及其电力输出功率接口。需量绑定
   独立于能源购售计费，不需要为同一计量点另外配置电量价格。
   可以编辑、删除绑定；这是可选费用项，不采用时保留空表，不影响其他计费及计算。
5. 点击“保存成本与计费绑定”，设备成本、能源购售和需量绑定在
   同一次草稿修订中保存。成功后重新读取服务器草稿，
   刷新或重进页面应保持全部关联。并发 409 保留未保存编辑，
   可明确选择“重载最新草稿”（将丢弃当前表单编辑）。
   即使模型中的最后一台设备已删除，仍允许用户明确移除遗留设备成本与
   计费绑定并保存空清单；
   不会因为设备数量为零自动清空或禁止保存。
6. 在途保存和重载期间表单会禁用；失败时保留编辑并展示错误与后端
   诊断。草稿保存只是登记用户的显式关系，后续项目校验和任务提交
   才是装配、价格引用及单位量纲的权威门禁；不得将“保存成功”
   等同于“优化已可计算”。

需量费按各运营自然月的实际最大受电功率计取，参与同一次优化，
不是全年峰值收费或求解后的附加估算。零费率仍记录真实月峰和零账单；
无绑定则没有月账单。月份日价格在财务配置中设置；规模关联维护在[提交任务](validation-and-tasks.md)的维护清单中填写。

## 配置项目财务

在工作台打开“财务配置”，先准备符合正式[财务格式](../../developer-guide/zh-CN/formats/finance-yaml.md)的完整 JSON 文档：

1. 已有画像时从列表选择并点击“引用/切换”；新画像先粘贴到“财务画像文档”，点击“登记”，再引用到项目。
2. 新画像的需量费项可在完整文档下方的结构化编辑区添加、修改或删除，再登记画像。填写费项标识与每月按最大功率计费的费率，单位随画像币种显示，例如 `CNY/kW`；不计需量费时目录可以为空。
3. 需要项目专属参数时，在“项目覆盖”填写覆盖文档并保存。需量费率编辑区只允许覆盖所引用画像中已有的费项，单位保持不变；撤销某项覆盖后使用画像费率。不再需要整个覆盖文档时点击“清空覆盖”。
4. 核对只读的“有效财务配置”。引用或覆盖变更会使原规划配置失效，提交前重新确认规划目标、变量和边界；选择税后优化时，规划目标明确采用税后 NPV，引用税画像本身不会自动更换目标。

结构化编辑区与 JSON 文本编辑的是同一份文档。保存、清空覆盖或切换画像及随后的重读期间，相关编辑暂时禁用，完成后恢复。保存失败时保留文档并显示诊断，按提示修正后重试。遇到版本冲突，先保留需要的编辑，再主动重载最新版本；重载会替换尚未保存的内容。评价周期、付款、维护清单和折现率仍在提交任务时确认，不写入财务画像或计算配置。

### 按月份配置日价格曲线

适用于每个自然月使用一条完整日价格曲线、相同月份逐年沿用的情况。若每年价格不同，继续使用“全期价格序列”，不选择月份日曲线。

1. 在“数据管理”上传完整一天的价格 CSV（`ies.price-series@1.0.0`，表头为 `step,price`），分辨率与项目一致：1h 为24点、30min 为48点、15min 为96点。从上传结果或版本详情复制“价格对象 ID”，不是数据集 ID；多个同价月份可以复用同一个对象。详见[数据准备](data-preparation.md#价格序列文件)。
2. 打开“财务配置”，在画像文档或项目覆盖下方找到对应能源价格的“价格来源”，选择“按月份选择日曲线”。项目覆盖只能修改已引用画像中存在的价格项。
3. 设置“日曲线分辨率”和“价格单位”，为1—12月填入价格对象 ID。可以先填一月并点击“全部月份引用一月曲线”，再替换价格不同的月份；十二个月必须全部填写。
4. 新画像点击“登记”后引用到项目；项目专属价格点击“保存覆盖”。核对“有效财务配置”，刷新后应仍显示保存的十二月来源。覆盖整项替换，不会自动从画像补齐缺少的月份；选择“沿用画像”可撤销该价格覆盖。
5. 财务变更后重新检查并保存规划配置，再发起计算。每天使用所属月份的日曲线，闰日使用二月曲线；已提交任务保持当时的价格来源，不随后续覆盖修改。

JSON 尚未填写完整时，页面提示结构不完整并保留原文，修正后可继续使用结构化编辑器。保存失败会保留编辑；实际对象缺失、不是完整一天、分辨率或单位不匹配会在提交时明确阻断，按诊断修正来源或引用后重试。保存成功不等于来源已通过任务提交核对。

## 填写配置

页面字段全部对应配置全文。新建项目打开本页时，时间限制按统一
部署配置的公开初值填入（当前 12 小时，可由部署者调整），其余字段
留空：精度下拉框的空选项表示未选择，必须由用户明确选择后才能保存。
部署初值加载失败时页面明确报错，不会静默留空冒充正常初值。

- 计算模式：文本，例如 `planning`；
- 生成器精确引用 / 求解器：文本，形如 `<稳定ID>@<语义化版本>`，
  例如 `ies.generator.highs_milp@5.0.0`；
- 计算精度：`low`、`medium`、`high` 三选一，必填；
- 时间限制(秒)：正整数，必填；
- 随机种子：可空，空表示不指定；
- 输出请求：JSON 数组，必填且不能为空；
- 预测配置：JSON 数组，可空；
- 阶段二收敛：JSON 对象，可空（空表示不适用）；
- 生成/求解选项：JSON 对象，可空。

计算配置使用 `2.0.0`，预测流程由所选算法是否依赖求解结果决定，与目标数量无关。内置 naive 属独立预测，求解前生成一次；仅有独立预测或无预测时，阶段二收敛留空。

税务方法与参数来自项目引用的财务配置，不放入本页计算配置。提交按所选生成器声明的能力判断是否支持税则和抵扣池；提示不支持时应调整生成器或财务配置，不能把税则留在输入中却按税前执行。金额是否含税与结果是否税后是两个不同口径。

选用已注册的耦合预测能力时，填写 `{"tolerance": 0.01, "max_iterations": 10}` 形式的收敛配置：容差是无量纲阈值，具体指标与参数按算法说明填写；轮数上限包含首次求解，至少为 2。独立序列保持固定，耦合序列随上一轮求解结果更新；达到上限未收敛会保留未收敛状态，不表示已经找到全局最优。上述数字仅为填写形态示例，不是默认值。

JSON 文本域内容非法时页面直接阻断保存并标出字段。
预测算法未注册或参数不符合该算法规则时，保存失败；收敛配置与算法依赖不相符时，提交任务会明确报错。旧 `1.0.0` 配置不再接受。

## 保存与读取

1. 首次保存：页面标题下方显示“尚未保存”，点击“保存计算配置”，
   成功后显示新 revision（例如 `当前 revision: v1`）。
2. 再次打开：页面自动填入最新 revision 全文。
3. 他人先保存导致冲突（409）：页面保留当前表单编辑不覆盖，
   仅提示冲突；确认要以最新 revision 为准时，点击
   “重新加载最新配置”（将丢弃未提交编辑），或修改后重试。
4. 输入非法（422）：页面展示后端返回的错误信息，不保存。

## 未保存的影响

项目校验在没有已保存配置时报告阻断问题（诊断码
`VALID-CONFIG-001`），任务提交入口在保存配置之前保持禁用。
提交时任务快照冻结所引用 revision 的配置正文与来源，
后续再保存新 revision 不改变既有任务快照。
