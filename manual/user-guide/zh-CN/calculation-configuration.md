# 计算配置

## 开始之前

先完成系统建模，并确认新增设备和存量设备的属性正确。计算配置的币种来自项目，页面不能在这里改币种。

## 填写经济参数

在“经济参数”中依次核对：

- 评价周期；
- 折现率；
- 税率；
- 折旧年限；
- 最低内部收益率。

百分比字段按页面显示的百分数填写，例如 `8` 表示 8%。最低内部收益率是独立硬约束，不能被其他目标权重抵消。

## 设置优化变量

“新增设备容量变量”用于规划新增容量：

1. 点击“添加变量”。
2. 填写唯一名称。
3. 选择连续、整数或 0/1 类型。
4. 填写初值、下界和上界，确保初值位于边界内。

“存量设备”列表只用于核对固定容量，不参与新增容量优化。

## 选择目标和约束

选择一个主目标，例如项目投资 IRR、NPV 或资本金 IRR 最大化。需要控制碳排放时，启用运行期碳排放上限并填写正数。

预定义约束应优先使用。高级自定义表达式适合熟悉变量名称和表达式规则的用户；出现表达式诊断时，应修正名称或公式，不要反复提交。

## 选择算法

一般保持“自动选择”。手动选择时必须确认算法支持当前变量类型；含整数或 0/1 变量的配置不能使用只支持连续变量的算法。

## 保存和校验

1. 点击“校验配置”。
2. 修复页面列出的字段错误或算法不兼容问题。
3. 点击“保存”。
4. 等待“配置已保存”并记下显示的配置版本。

“恢复默认配置”会替换当前填写内容，使用前先确认。配置标记为冻结后不能继续保存；需要试验另一套配置时，可从项目列表复制项目后再修改。
