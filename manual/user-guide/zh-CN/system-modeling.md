# 系统建模

## 开始之前

开始搭建模型前，请留意工作台顶部的币种与自动保存状态。画布修改会自动保存到草稿，保存状态随实际请求结果更新；若出现保存失败，请保持页面打开并检查与服务器的连接后重试；若多人或跨窗口同时修改导致冲突，可根据提示选择加载服务器最新版本。

## 页面加载与刷新

- 打开页面或点击工具栏“刷新”时，画布处于只读加载状态，读取完成后即可编辑。
- 若读取失败，页面会显示错误信息与“重试”按钮，不会显示空白画布冒充空项目；等待“已保存”后再刷新可避免覆盖刚提交的修改。

## 添加与配置设备

1. 打开左侧“系统建模”。
2. 从左侧“设备面板”将所需设备拖入画布（空画布也支持按提示双击添加）。
3. 点击画布中的设备节点，在右侧“编辑设备”侧栏配置：
   - **设备名称与资产性质**：填写便于识别的名称，并选择“存量设备”（已存在容量，不计入新增建设投资）或“新增设备”（可参与新建投资与容量规划）。
   - **技术参数**：按页面标明的单位与范围填写参数；标有“可作优化变量”的参数可在后续“规划配置”中设为待优化决策量。

### 使用“单位装机出力（电）”

若项目已具备标准化出力曲线而非气象辐照数据，请在设备面板选择**单位装机出力（电）**（区别于使用太阳辐照与温度的“光伏”设备）：

1. 在“数据管理”上传并绑定曲线数据集（设备标识 `ies.device.power_curve`，数据列为 `unit_output`，单位声明为 `1`，代表单位装机出力 kW/kW）。
2. 将设备拖入画布，在侧栏填写参考装机容量 `installed_capacity_kw`（kW）；若需由优化决定装机规模，后续可在“规划配置”中将该参数设为规划变量。
3. 在“预定义接口来源”为 `unit_output` 选择 `data_repeat`（典型日/周/年循环）并绑定对应数据集版本。

*(注：若原始出力数据为某既有电站的绝对出力 kW，上传前须先除以该电站装机容量换算为 `0..1` 标幺值。模型如需逆变器交流限额或弃光关系，可通过项目已保存模型入口在完整 YAML 中显式声明。)*

### 规划储能容量

内置“储能”设备支持同时将 `capacity_kwh`（kWh）与 `rated_power_kw`（kW）交由规划配置优化。初始电量会随优化求得的容量按初始 SOC 比例同步缩放。软件不自动假设储能时长上限或终期电量要求，如需此类边界请在“规划配置”中显式填写。

### 使用项目已保存模型

在项目“模型”页校验保存成功的自定义模型会与内置设备一并出现在设备面板中（同名模型可通过旁注的模型 ID 与悬停提示区分）。拖入画布时将自动带入模板填写的数据来源，后续仍可在侧栏独立修改。

- 项目模型仅在当前项目内可见；恢复到创建该模型之前的历史版本后，设备面板仅展示当时有效的模型集合（后续保存或删除模型操作会按项目模型库重建可用列表）。

## 连接端口与网络边界

1. 将源设备的输出端口拖向目标设备的输入端口即可建立连线；点击连线可查看载体类型或点击“断开连接”。
2. 端口连线必须满足能源载体相同、输出连输入（或兼容双向端口），不支持设备自连、重复连线或连接辐照/负荷等预定义资源端口。
3. **未连接端口规则**：同一设备的不同端口不会自动直连；画布中未连接的外部输入/输出端口在仿真中按零流量（关闭边界）处理，不提供免费外部供给。外部购电、燃料供给或余电外送须接入相应的显式源/汇设备。

## 编辑、删除与画布校验

- 连续编辑多个属性或改名时，系统按顺序提交保存并在“已保存”后刷新状态。删除设备时需在三秒内再次点击确认，同时会移除关联连线。
- 点击工具栏“校验”可即时定位模型与连接错误（如缺失数据绑定、载体冲突），但提交任务前仍需前往独立“校验”页运行包含数据与配置在内的全项目校验。
