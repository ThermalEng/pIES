# 系统建模

## 开始之前

先确认项目币种正确（项目不设置时区）。画布会自动保存，但网络中断或多人同时修改可能产生冲突；开始前留意工作台顶部的保存状态。

## 打开与加载

- 打开页面先显示加载中，此时设备面板与画布不可写；只有读到服务器真实内容后才可编辑。
- 模型读取失败时页面明确报错并提供“重试”，不会显示可编辑的空画布，也不会标“已保存”；重试只重新读取，不创建或修改任何内容。点击重试后先显示加载中，请求发出后不可重复点击。
- 成功读取但尚无设备时，空画布是合法可编辑空态，可按提示添加设备。
- 手动“刷新”会重新读取服务器版本：刷新过程中画布只读（不可增删改、不可校验），刷新失败会保留旧图并持续提示，直到再次读取成功才恢复编辑；保存进行中“刷新”不可用，避免旧版本覆盖正在保存的内容。

## 添加设备

1. 打开“系统建模”。
2. 在左侧“设备面板”找到需要的设备。面板内容由当前系统实际可用的设备目录决定。
3. 把设备拖到画布；空画布也支持按页面提示双击添加。
4. 点击设备节点，打开“编辑设备”侧栏。
5. 修改设备名称，选择“存量设备”或“新增设备”。
6. 按字段显示的单位和范围填写参数；标有“可作优化变量”的参数可在后续配置中参与规划。

“存量设备”表示容量已经存在，通常不参与新增容量优化；“新增设备”表示系统可以在给定边界内规划容量。

### 使用单位装机出力曲线

已有单位装机出力数据时，在设备面板选择“单位装机出力（电）”。它与原“光伏”是两个独立选项：前者直接使用出力曲线，后者使用太阳辐照和环境温度；不要把绝对出力或辐照数据当作单位装机曲线。

1. 在“数据管理”上传并绑定曲线的数据集版本，步骤见[数据准备](data-preparation.md)。文件中的设备标识为 `ies.device.power_curve`，数据列为 `unit_output`，单位声明为 `# unit.unit_output: 1`，分辨率须与项目一致。
2. 将“单位装机出力（电）”拖到画布，点击节点，在侧栏填写 `installed_capacity_kw`，单位为 kW。
3. 在“预定义接口来源”中，为 `unit_output` 选择与文件一致的来源模式及已绑定的数据集版本。重复使用典型曲线可选择 `data_repeat`；文件的 `step` 从0开始连续编号。后续各运营年沿完整曲线连续循环，不额外按公历日期对齐。
4. 等待“已保存”，重新打开后核对容量、来源模式和版本。将 `electric_out` 接到电力网络，再继续配置规划与计算。

`unit_output` 的单位 `1` 表示 kW/kW：例如曲线值0.25、容量40 kW时，该步输出10 kW；容量80 kW时输出20 kW。原始数据若是某座电站的绝对kW出力，应先除以该电站对应的装机kW，再上传；不要直接填写绝对出力。

固定容量使用侧栏填写值；需要优化容量时，在“规划配置”将该实例的 `installed_capacity_kw` 设为规划变量并填写边界，单位仍为kW。此时计算使用求得的容量，而不是把侧栏初值固定为最终方案。财务绑定仍需单独配置，曲线本身不包含建设费或收益假设。

### 规划储能容量

内置“储能”可将 `capacity_kwh`（kWh）与 `rated_power_kw`（kW）交给“规划配置”优化，也可使用侧栏填写的固定值。初始 SOC、最小／最大 SOC 和充放电效率仍按所填参数生效，初始电量随本次求得的容量变化；零容量不产生免费电量。

容量、功率边界和两者的时长关系由项目明确配置；软件不自动设定储能时长、容量上限或终期 SOC。当前互斥求解需要非退化充放电功率的明确有限上界；遇到能力诊断时检查规划边界，不要把容量改成固定值来掩盖问题。成本与指定年份维护费用另在财务绑定和维护清单中配置，共同使用同一次求解的规模。

### 使用项目已保存模型

在“模型页”保存成功的模型属于当前项目。回到“系统建模”后，它会和内置设备一起出现在设备面板；拖放、改名、填写参数和连线方式与内置设备相同。

模板中填写的数据来源在添加实例时带入该实例，之后可在侧栏“预定义接口来源”中修改。选择 `constant` 时填写常量；选择数据来源时选择本项目的数据集版本，`data_predict` 还须填写目标类型并在计算配置中选择相容的预测算法。未填完的常量保留在本地，离开输入框后留意错误和保存提示。数据集版本加载失败时点击“重试”，不要把失败当作没有数据。

改名保留实例当前参数和来源，不重新应用模板输入。若添加后出现模型读取失败，设备可能已经保存；先点击“重试”读取服务器内容，再继续编辑，不要重复添加。

- 项目模型只在本项目可用：其他项目看不到，也不能引用。
- 恢复一个不含该模型的历史版本后，恢复点之后保存的模型不再出现在设备面板；项目模型列表本身仍保留这些已保存资产。
- 在恢复之后再保存或删除模型时，设备面板按项目模型列表重建：列表中的其他资产（包括恢复点之前的）会一并重新可用；当前没有单独的“启用/停用已保存模型”入口。

## 连接端口

1. 找到源设备的输出端口和目标设备的输入端口。
2. 从输出端口拖到输入端口。
3. 点击连线，在连接详情中核对源、汇、能源类型和连接类型。

端口必须同时满足能源类型和方向要求。不能连接设备自身，不能重复连接同一对端口，太阳辐射等资源端口不能手工连线。出现红色连接提示时，按提示重新选择端口，不要修改无关参数来绕过检查。

## 编辑、断开和删除

- 点击设备可修改属性和参数；离开输入框后留意保存状态。
- 点击连线后可选择“断开连接”。
- 删除设备需要在三秒内再次确认，相关连接也会被删除。
- 工具栏提供放大、缩小、适应视图和校验。

## 检查保存状态

- “已保存”：服务器已接受当前修改。
- “有未保存更改”或“保存中”：等待完成后再继续提交任务。
- “保存失败”：保持页面打开，检查网络后重试。
- “保存冲突”：项目已在其他会话修改。优先选择“加载服务器版本”并重新核对；只有确认不会覆盖他人工作时才选择强制保存。

## 校验模型

点击画布工具栏“校验”。如果出现诊断，可点击“定位”找到相关设备。画布校验用于即时反馈；提交任务前仍必须到独立“校验”页面运行完整检查。
