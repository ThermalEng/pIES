# pIES 使用者指南

本指南面向第一次使用 pIES 的规划工程师、能源工程人员与系统管理员，按界面操作顺序组织。页面按钮与提示以当前简体中文界面为准；如需了解更多概念或版本限制，可参考[概念、单位与当前限制](concepts-and-limits.md)。

## 章节导航

1. [快速开始](getting-started.md)：系统登录、会话与外观偏好、创建首个项目并体验流程。
2. [项目与访问权限](projects-and-access.md)：项目列表、归档与删除、项目包分享、版本固化与恢复。
3. [系统建模](system-modeling.md)：画布设备配置、模型参数与预定义接口、端口连接、画布校验，以及“自定义”页与 `1.2.0` 参考设备模型。
4. [数据准备](data-preparation.md)：模板下载、上传设备数据与价格序列、质量诊断与项目绑定。
5. [计算配置](calculation-configuration.md)：配置财务规则、设备成本与计费绑定、规划目标约束，以及 13 字段计算配置、阶段插件目录与并联评价器。
6. [校验与任务](validation-and-tasks.md)：全项目校验、评价参数确认、单向阶段流水线执行、任务提交、进度观测与重试排查。
7. [结果与导出](results-and-exports.md)：解读求解状态、财务评价、自描述第三方评价报告、单评价器重试、步曲线、基准差额、方案应用与导出报告。
8. [账户、管理与故障排查](administration-and-troubleshooting.md)：个人设置、管理员账号/生态治理/审计操作及常见异常与升级排查。
9. [概念、单位与当前限制](concepts-and-limits.md)：核心版本概念、单位时间规范与当前版本功能边界。

## 标准业务工作流

```text
登录 → 新建项目 → 系统建模 → 数据准备 → 计算配置
     → 项目校验 → 提交任务 → 结果分析 → 应用方案 / 导出交付
```
