# IES Plan 用户指南

本指南面向规划工程师、能源工程人员和系统管理员，按用户目标和业务流程组织。

## 内容范围

- 安装、启动、登录和首次配置；
- 项目创建、复制、归档和删除；
- 设备建模、端口连接和模型诊断；
- 数据模板、上传、质量检查和绑定；
- 经济参数、环境参数和计算配置；
- 任务提交、状态、取消、重试和失败处理；
- 结果、财务指标、有效性评估和证据解释；
- 项目包与报告的导入、导出；
- 管理员账号、安全、容量和健康检查；
- 常见问题、错误码和可执行修复步骤。
