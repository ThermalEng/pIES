# pIES 使用者指南

本指南假定你第一次接触 pIES，不要求了解程序代码、接口或数据库。章节按 GUI 中的实际工作顺序组织；每项操作说明前置条件、操作步骤、预期结果和失败时的处理办法。

## 建议阅读顺序

1. [快速开始](getting-started.md)：启动、登录并建立第一个项目；
2. [项目与访问权限](projects-and-access.md)：项目生命周期、复制、共享与所有权；
3. [系统建模](system-modeling.md)：在画布添加设备、设置参数并连接端口；
4. [数据准备](data-preparation.md)：下载模板、上传、检查并绑定数据；
5. [计算配置](calculation-configuration.md)：设置经济参数、变量、目标、约束和算法；
6. [校验与任务](validation-and-tasks.md)：消除阻断问题并提交后台计算；
7. [结果与导出](results-and-exports.md)：解释结果、评估、候选方案和报告；
8. [账户、管理与故障排查](administration-and-troubleshooting.md)；
9. [概念、单位与当前限制](concepts-and-limits.md)。

## 一条完整工作流

```text
登录 → 新建项目 → 系统建模 → 数据绑定 → 计算配置
     → 项目校验 → 提交任务 → 结果分析 → 导出
```

页面名称、按钮名称和提示语以当前中文界面为准。若界面与文档不一致，请记录页面、操作步骤、产品版本和可见诊断码，再按故障排查章节处理。
