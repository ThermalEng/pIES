# 概念、单位与当前限制

## 常见“版本”概念区分

| 概念 | 含义与用途 |
|---|---|
| 产品版本 | pIES 软件发行版本（如 `1.1.0`），用于判断可用界面功能与报告问题 |
| 项目草稿 | 当前工作区中的可编辑内容；自动保存仅更新草稿，不会形成永久版本 |
| 项目版本 | 在“版本历史”主动固化或提交计算时生成的不可变设计基线，用于历史回溯与恢复 |
| 数据集版本 | 数据文件每次上传校验形成的不可变版本，绑定到项目后不会随后续上传自动切换 |
| 计算配置修订 | “计算配置”或“规划配置”每次保存生成的新修订，任务提交时按选中修订冻结 |
| 计算快照与证据 | 任务提交瞬间固化的全部输入与求得结果的唯一依据 |

## 单位与时间规则

- **单位规范**：功率常用 `kW`、能量常用 `kWh`、温度常用 `°C`、比例在界面表单以百分数显示（如 `8%` 填入 `8`）、金额遵循项目创建时选定的单一币种（不支持同一项目自动换汇）。请勿把单位文字写进纯数值框，或在数据上传时混用功率与能量单位。
- **时间基准**：项目本身不设时区；通用时间戳 CSV 须在数据集版本中声明单一固定 UTC 偏移（不支持夏令时跳变），自描述 step 文件按连续整数步计数。全年点数由项目创建时选定的运行起始年按实际公历推导（闰年自动多出一天点数）。

## 财务评价和 IRR

- 项目评价采用覆盖建设期与运营期的完整含税现金流，支持对已冻结基准执行对比分析（`difference` 模式下双方各自按自身税务规则计税后再作差，不对差额重新套用税率）。
- 仅配置含税价格或展示税目标签并不代表启用税务计算；需要计税时须在财务文档中显式配置税率、规则、抵扣池及适用范围（当前范围聚焦项目投资税后评价，不包含融资、资本金评价与税务申报）。
- IRR 结果需结合其状态（正常 / 无解 / 多解 / 退化 / 超出定义域 / 数值失败）解读，不存在“最低 IRR”硬约束输入。
- 若启用了互斥或分段税务等需要有限上下界的模型关系却未提供或无法推导出所需界，任务提交或构模诊断会精确指出关系来源与缺失边界，按提示补充合法物理范围即可。

## 费用口径

- **年度运维与换新**：常年固定运维配置在 `annual_fixed_om`；按运行量/发电量计费配置在 `period_variable_om`；特定年份大修或设备换新在提交任务的 `maintenance_expenses` 显式填写（不接受无年份、无时间维度的标量全期运维金额）。*(燃气等体积流量当前使用 `m³`/`m³/h` 等页面支持单位。)*
- **选建与固定费用**：是否建设某个可选单元与固定费用是否触发通过建设单元及实例的费用发生条件显式关联，未声明发生条件的固定成本按无条件发生计入。

## 当前 `1.1.0` 限制

- 在 `1.1.0` 版本中，当前仅支持系统四维自动评估（暂不提供人工评分保存入口）；
- 项目包导入已支持上传提案与确认创建，暂未提供待处理提案管理列表；
- 数据集“版本列表”暂不支持在线预览逐行数据表；
- 管理员审计日志当前仅支持只读查询，运维巡检与备份恢复需在服务端操作；
- 用户自定义模型库、算法插件上传与共享园地功能将在后续 `1.x` 版本交付；
- 官方帮助中心同步提供简体中文与英文版。

后续规划详见 [Roadmap](../../changelog/roadmap.md)。
