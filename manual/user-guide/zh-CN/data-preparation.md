# 数据准备

## 选择准备方式

“数据管理”提供三种入口：

- “下载模板”：从后端取得 CSV 表头和示例；下载失败时页面明确报错且不下载，不得当作已成功，稍后可再点下载重试；
- “内置样例数据”：生成可重复的全年逐时演示数据；
- “上传数据”：上传正式 CSV。

样例数据只用于熟悉流程，不代表真实项目条件。

## 时间要求

通用时间戳 CSV 按标准非闰年 365 天处理，支持 15 分钟、30 分钟和 60 分钟分辨率。对应的典型行数分别是 35040、17520 和 8760 行。

通用 CSV 首列时间戳必须严格递增且不重复；同一数据集使用一个固定 UTC 偏移（在数据集版本中声明），不使用夏令时跳变。设备数据 step 文件使用从 0 开始的连续 step，无时区。

设备数据 step CSV（`ies.device-data`）统一声明 `2.1.0` 字头（旧 `2.0.0` 不再接受），`source_mode` 只能为 `data_repeat`、`data_full`、`data_predict`（`constant` 直接在绑定中给值，没有 CSV）；文件自带 `# resolution` 且须与项目基线一致，`step` 从 0 开始连续递增，每格为有限数值，每数据列有 `unit.<列>` 声明；`data_repeat` 不设统一全年行数要求（完整日/周/年均可），`data_full` 必须覆盖全周期全部点数；来源绑定（设备、接口、模式）在装配处显式声明，不由列名猜测。建模页面的来源声明入口目前只提供 `data_repeat`/`data_predict`；`data_full` 全期文件可按 `2.1.0` 上传，其页面声明入口暂未提供。

## 上传 CSV

1. 点击“上传数据”。
2. 输入数据集名称。
3. 通用时间戳文件：选择时间分辨率和固定 UTC 偏移，并在“字段描述”中逐项填写 CSV 字段名、单位和说明（可添加或删除字段）；设备数据 step 文件：选择文件后页面会提示其自描述模式，分辨率取文件值，不再填写字段与 UTC 偏移。
4. 需要时填写许可证和数据说明。
5. 选择 CSV 文件并点击“上传数据”。

通用 CSV 常用字段包括电、热、冷负荷，环境温度、太阳辐照、电价和电网排放因子。请以下载模板及上传页面显示的字段要求为准，不要仅凭列顺序猜测含义。step 文件的列 ID 必须与所绑设备预定义接口一致，详见设备数据 CSV 契约。

## 价格序列文件

价格文件使用 `ies.price-series@1.0.0`，元数据声明分辨率和价格单位，表头为 `step,price`，`step` 从0连续递增。通过同一个“上传数据”入口上传，页面识别后采用文件分辨率和单位，不填写通用字段与 UTC 偏移；价格可以为正、零或负的有限数值。

全期价格文件须覆盖完整运营期；用于月份日曲线的文件只需完整一天（1h／30min／15min 分别为24／48／96点）。上传成功后，在结果或版本详情复制“价格对象 ID”，到[财务配置](calculation-configuration.md#按月份配置日价格曲线)填写引用。价格引用不使用普通设备数据的“绑定到项目”操作，也不把文件名或数据集 ID 当成价格对象 ID。上传只检查文件自身，价格与项目时轴的对应关系在任务提交时核对。

## 检查上传结果

上传完成后先看质量状态和诊断：

- “质量良好”或“通过”表示当前检查未发现阻断问题；
- 阻断性问题必须修正源文件后上传新版本；
- 上传成功只表示文件已接收，不表示已经供项目计算使用。

点击“版本列表”可查看数据集的不同版本及溯源信息。“数据预览”当前版本不提供行级数据预览：打开后会明确提示暂不可用，并显示该数据集最新版本的字段信息，不会显示空表冒充数据内容；这不影响质量报告和绑定操作。

## 绑定到项目

对质量通过的最新版本点击“绑定到项目”，也可在“版本列表”中绑定或解除指定版本。成功后页面重新读取项目草稿，列表标记和版本对话框显示同一绑定状态；已绑定版本的快速绑定按钮不可重复点击。刷新页面后应保持服务器已保存的状态。

若提示绑定或解绑已写入、但状态读取失败，点击页面的重新读取按钮确认结果。此操作只重读，不再次提交绑定或解绑；不要将读取失败当作写入未成功。

如果重新上传了新版本，需要再次核对并绑定；不要假设项目自动切换到最新文件。

## 常见失败

- 数据集或版本列表加载失败：页面明确报错并可重试，不要把失败当作“无版本”；重试只重新读取，不上传或绑定。
- 行数不对：检查分辨率、表头和是否包含闰日。
- 时间重复或倒序：按时间排序并移除重复记录。
- step 文件被拒：检查 `# schema/# schema_version` 头、文件分辨率与上传选择一致、`step` 自 0 连续、每列有 `unit.<列>` 声明、未知 `# schema` 会被直接拒绝。
- 单位不明：在字段定义中填写明确单位，不要把单位写进数值单元格。
- 质量未通过：按诊断修复并上传新版本，不能直接绑定。
- 绑定按钮不可用：确认数据集已有版本、质量通过且尚未绑定。
