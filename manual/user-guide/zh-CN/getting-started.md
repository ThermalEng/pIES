# 快速开始

## 准备信息

向系统管理员确认以下信息后即可登录使用：

- pIES 访问地址；
- 个人账号与初始密码；
- 新项目选用的结算币种（项目不设置时区，通用数据文件的 UTC 偏移在数据集上传时单独声明）。

如需自行启动或从 `1.1.x` 升级至 `1.2.0`，请先参考[部署与运行](../../developer-guide/zh-CN/deployment.md)。

## 登录与会话

1. 在浏览器打开 pIES 访问地址。
2. 输入用户名与密码，选择界面语言后点击“登录”。
3. 若系统提示首次登录改密，输入当前密码及两次新密码并重新登录。

**使用提示**：

- **语言与深浅色模式**：登录页和顶部导航栏均提供语言（中文 / EN）及浅色/深色模式切换按钮（支持键盘聚焦后回车或空格触发）。偏好保存在当前浏览器本地，刷新或退出登录后依然保留，不会随账号同步到其他设备。
- **多窗口独立会话**：同一账号可同时在多个浏览器或窗口登录，各窗口退出操作仅结束当前会话；修改密码或管理员停用账号会使旧会话统一失效。
- **空闲过期与退出**：会话默认在无操作 8 小时后自动过期（期间的真实点击、画布拖拽、键盘输入和滚动会自动续期，仅挂机轮询不续期）。后台已提交的计算任务不会因会话过期或退出登录而取消。单次网络请求超时（常规请求 60 秒、文件下载 120 秒）不会触发登出。

## 建立第一个项目

1. 在“项目列表”点击“新建项目”。
2. 填写项目名称与结算币种（项目内所有金额统一按该币种核算，不支持自动换汇）。
3. 填写**运行起始年**（公历整数年，如 `2026`；系统会自动按实际公历推导闰年）并选择**计算分辨率**（如 `1h`）。**起始年与分辨率创建后不可更改**。
4. 点击“确认”并在列表中打开项目，进入工作台。

工作台左侧导航依次为：**系统建模**、**数据管理**、**计算配置**、**校验**、**任务中心**、**结果分析**与**导出**（新项目默认打开“任务中心”）；顶部导航另外提供全局**自定义**（“模型与算法”双页签，管理模板、本地导入及市场插件）与管理员专属的**生态治理**（`/admin/ecosystem`）。

## 快速体验完整流程

首次熟悉界面时，可按以下顺序完成一次端到端演算：

1. 在**系统建模**拖拽并配置设备、连接端口；
2. 在**数据管理**点击“内置样例数据”生成一套演示负荷与气象数据，质量通过后点击“绑定到项目”；
3. 在**计算配置**填写经济参数、规划目标与求解配置并保存；
4. 在**校验**运行项目检查，确认无阻断错误；
5. 在**任务中心**填写评价参数并提交计算任务；
6. 任务完成后在**结果分析**查看方案、曲线与财务指标，并在**导出**下载 Excel 报告。

*(注：内置样例数据仅用于功能演示，正式工程项目请上传真实数据并核对参数。)*

## 常见登录问题

- **无法打开页面**：核对访问地址、本地网络以及服务容器是否就绪。
- **登录失败**：核对用户名与密码；如提示账号已停用，请联系管理员处理。
- **工作台提示保存失败**：查看错误信息并确认网络可用，重新保存后核对页面上的自动保存状态。

下一步阅读[项目与访问权限](projects-and-access.md)。
