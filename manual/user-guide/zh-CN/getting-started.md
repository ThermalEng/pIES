# 快速开始

> 适用版本：0.1.x
> 状态：当前功能说明

## 启动系统

IES Plan 使用 Docker 部署。在项目根目录执行：

```bash
docker compose up -d --build
```

默认访问地址为 `http://localhost:8080`。默认管理员用户名为 `admin`，初始密码由部署环境变量 `IESPLAN_DEFAULT_ADMIN_PASSWORD` 决定；首次登录后必须修改密码。

生产环境必须另外配置高强度 `IESPLAN_SECRET_KEY`、数据库密码和 HTTPS，不能直接使用开发默认值。

## 完成第一个项目

1. 在项目列表创建项目，填写名称、币种和固定 UTC 偏移。
2. 打开项目工作台，在“模型”中添加设备并连接真实端口。
3. 在“数据”中上传年度时序数据，检查分辨率、单位和质量诊断。
4. 在“配置”中设置设备参数、经济参数、变量、目标、约束和算法。
5. 在“校验”中修复所有阻断性诊断。
6. 在“任务”中提交方案评价、规划优化或不确定性分析。
7. 在“结果”中查看指标、逐时曲线和有效性评估。
8. 在“导出”中生成 Excel 报告或项目包。

## 重要概念

- **草稿**：当前可编辑内容。自动保存不会自动创建永久版本。
- **项目版本**：用户明确保存的不可变历史节点。
- **计算快照**：任务提交时冻结的模型、数据、配置和版本信息；任务不会读取之后变化的草稿。
- **阻断性诊断**：必须修复后才能提交任务的问题。
- **证据**：与任务、快照和结果绑定的不可变计算依据。

## 支持范围

当前界面支持电、热、冷三类能源载体，以及电网连接、光伏、电池、电/热/冷负荷、热泵、燃气锅炉和电制冷机等设备。任务页面当前可直接提交方案评价、规划优化和不确定性分析。

如页面行为与本指南不一致，应记录产品版本、操作步骤和诊断码，并按[故障排查](administration-and-troubleshooting.md)处理。
