# 帮助中心语言目录 / Help Center Locale Registry

- [简体中文目录](SUMMARY.zh-CN.md)
- [English Table of Contents](SUMMARY.en-US.md)

当前正式文档同步发布简体中文（`zh-CN`）与英文（`en-US`）两个语言版本。新增语言时必须补齐全部同构章节并通过验收，才能在此登记对应 `SUMMARY.<locale>.md`；当请求语言缺失时，帮助中心不得用其他语言内容静默冒充。

每个语言目录必须包含“使用者指南 / User Guide”、“开发者指南 / Developer Guide”和“更新日志 / Changelog”三个并列一级节点，并保持相同的稳定章节 ID。
