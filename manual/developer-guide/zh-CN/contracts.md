# API 与数据契约

> 状态：生效目标契约；现有端点正在迁移

## JSON

- UTF-8 与 `application/json`；
- 字段统一 `snake_case`；
- 外部 ID 是不透明十进制字符串；
- 枚举使用小写 `snake_case`；
- 比例规范值为 `0..1`；
- 精确金额使用十进制定点字符串；
- 时间戳使用带 `Z` 的 ISO 8601 UTC；
- 长期文档、快照、证据和插件规格包含 `schema_version`；
- 禁止 `NaN`、Infinity 和依靠默认值掩盖缺失字段。

成功响应统一为：

```json
{"data": {}, "meta": {}}
```

错误响应统一包含 `code`、`message_key`、`severity`、`blocking`、`params`、`location`、`fix_hint_key` 和 `ref_ids`。后端不返回面向用户的硬编码文案或内部堆栈。

## DTO 边界

DTO 是公开请求/响应结构，不是 ORM，也不是为某个 React 组件定制的临时结构。前端负责表单字符串、百分比和简单展示单位转换；后端负责结构、权限、范围、量纲和领域约束校验。

## 单位

API 字段必须由 schema 固定单位，或使用明确的 `{value, unit}`。业务单位只在装配边界转换为引擎 SI；引擎输出在公开结果边界转换。禁止在业务代码散落 `×1000`、`×3600` 或 `/100`。

## HTTP

GET 只读，创建返回 201，异步任务返回 202。可重试写操作使用幂等键，并发修改使用 revision/ETag 等乐观锁。上传使用 multipart 或对象协议，下载使用短期授权，客户端不得拼对象路径。

当前实现与目标契约的差异应记录在 `docs/` 的审查和迁移计划中；不能通过客户端兼容分支把差异永久化。
