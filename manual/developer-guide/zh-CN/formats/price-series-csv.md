# 价格序列 CSV

> 契约标识：`ies.price-series`；目标 schema：`1.0.0`；推荐文件名：`<price-id>.price.csv`。文件统一声明 `1.0.0`，无旧版本兼容。
> 文档状态：生效目标契约；本页只定义目标文件语义，不声明实现进度。

价格序列 CSV 独立于带 `device_id` 的设备数据 CSV，用于人工准备或工具导出的能源价格序列。它把“采样间隔、价格单位”写进文件本身；`step` 从 `0` 开始连续编号，与项目全期时轴的点序号一一对应（`step` 即全期第几个点，不携带年份，年差直接体现在不同 `step` 的不同价格上）。用户必须在导入前处理好数据的准确性、完整性和对齐关系；系统在用户输入边界只校验，不重采样、插值、聚合或自动补齐。上传时不要求已知项目年限；全期覆盖在任务提交边界核对（取得已确认评价年限后），不一致阻断且不重采样。

## 文件结构示例

下例只节选数据行以展示结构，不是可通过校验的完整文件。正式文件必须包含其来源语义所需的完整数据行。

```csv
# schema: ies.price-series
# schema_version: 1.0.0
# resolution: 1h
# unit: CNY/kWh
step,price
0,0.7
1,0.7
2,0.35
```

## 文件结构

文件依次由三部分组成：

1. 以 `# ` 开头的元数据行；
2. 一行 CSV 表头；
3. 一行或多行数据（至少一行，空文件只能用于非法样例测试）。

元数据只能出现在表头之前，每个键只能出现一次。数据区不允许穿插注释。

## 必需元数据

| 键 | 含义 |
|---|---|
| `schema` | 固定为 `ies.price-series` |
| `schema_version` | 固定为 `1.0.0` |
| `resolution` | 采样间隔：`15min` / `30min` / `1h`；须与上传表单的分辨率一致 |
| `unit` | 价格单位，量纲 = currency / 能源单位（如 `CNY/kWh`）；须与财务 Profile/Overrides 中引用该序列的价格条目单位一致 |

未知元数据键即拒绝；缺少任一必需键即拒绝。

## 表头与数据行

表头必须恰为两列 `step,price`（列名大小写敏感，不接受多列或乱序）。

- `step`：整数，从 `0` 开始逐行 `+1` 连续递增，不允许跳号、重号、乱序；
- `price`：有限 Decimal（`Decimal` 文本），正、零、负均合法，禁止 `NaN`/`Infinity`；值保持原文精度落盘，物化时再换算。

## 上传与引用

- 同数据集上传入口按文件自描述（`# schema: ies.price-series`）识别：文件自身格式/数值校验、写对象并返回对象 ID（`oid`，随机对象 ID，不是内容 hash、路径或数据集版本）；上传响应质量报告的 `price_object_id` 即该值，财务 `time_series.ref` 即填该值。
- 财务 Profile/Overrides 只存 `ref` + `series_meta`（`resolution`/`point_count`/`unit`），不内联价格值；任务提交时以用户已确认的全期时轴对实际对象序列做唯一一次覆盖/声明元数据核对（实长、分辨率、单位），冻结对象引用；Worker 从已冻结对象按可信流程读取/物化，不再做完整性复核。
- 计价语义见[财务 YAML 契约](finance-yaml.md)「计价规则」：逐点 `Σ price[t]×e[t]`，`constant` 同一逐点语义；负价按方向自然反转。
