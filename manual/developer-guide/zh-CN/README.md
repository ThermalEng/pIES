# IES Plan 开发者指南

本指南面向扩展开发者、集成开发者、维护者和项目贡献者，发布稳定的架构原则、公共契约、扩展方法和维护要求。

## 必读

1. [架构宪法](ARCHITECTURE_CONSTITUTION.md)：开发者指南总则和最高架构规范；
2. [系统架构与模块边界](architecture.md)；
3. [API 与数据契约](contracts.md)；
4. [扩展开发](extensions.md)；
5. [开发、测试与文档](development.md)；
6. 根目录 `docs/` 中的过程文档只用于当前开发，不自动构成稳定公开契约。

## 内容边界

本目录只保存经过确认、可以长期维护的开发者文档。临时方案、差距分析、审查记录、实施日志和未定稿规格放在根目录 `docs/`，不能直接当作对外开发契约。

章节顺序由[简体中文帮助目录](../../SUMMARY.zh-CN.md)统一定义，用户指南和开发者指南在帮助中心目录树中是并列一级节点。
