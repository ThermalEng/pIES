# 模型与算法扩展指南

> 文档状态：生效目标指南；目标产品版本：`1.1.0`；上位规范：[架构宪法](ARCHITECTURE_CONSTITUTION.md)；相关格式：[设备模型 YAML](formats/device-model-yaml.md)、[算法插件包](formats/algorithm-plugin-package.md)

本指南规定用户自定义设备模型、算法插件包与共享园地（规划于 `1.1.0` 交付）的长期交付标准、身份版本模型与隔离安全边界。

## 核心架构定位

“模型与算法”面向已登录工程师开放，包含**模型库**、**算法插件**与**共享园地**三个入口：

- **模型库**：基于 `ies.device-model` YAML 交付用户设备模型。网页结构化表单、在线 YAML 编辑与 YAML 上传三条入口共享同一后端解析与校验门禁，最终生成一致的规范模型对象。
- **算法插件**：基于 `ies.algorithm-plugin` ZIP 交付用户自定义的装配加工程序与求解算法程序。上传包由独立容器化隔离运行器校验并执行，Web、API 与普通 Worker 进程永不加载或执行用户 Python 代码。
- **共享园地**：所有者可将已校验通过的不可变内容发布申请共享，经管理员批准后供其他用户浏览与安装。

## 身份、不可变发布与安装模型

| 对象 | 稳定标识 | 发布固定规则 | 命名与引用原则 |
|---|---|---|---|
| 用户设备模型 | `user.<public_namespace>.device.<slug>` | 单调递增 `revision` + `schema_version` + 校验回执 | `public_namespace` 由密码学安全随机源分配且终身不变；不设单设备语义版本 |
| 用户算法插件 | 命名空间 `plugin_id` | 精确三段式语义版本 + 完整依赖锁 | 修改入口或 Schema 必须升级版本 |
| 共享园地安装 | `CatalogInstallation` 引用记录 | 仅指向同一不可变发布，不复制底层文件 | 停止共享或卸载不影响历史任务与项目版本追溯 |

- 项目与计算配置只能引用已安装且状态为 `selectable=true` 的精确设备 `revision` 或插件版本，不允许引用草稿或 `latest`。
- 已发布内容不可原地修改；相同规范内容的重复发布保持幂等。

## 设备模型库规范

1. **纯技术语义**：遵循[设备模型 YAML](formats/device-model-yaml.md)，仅包含稳定标识、非时变 `properties`、五类 `interfaces` 与受限声明式 `equations`；严禁夹带价格、成本、计算精度或代码路径。
2. **校验门禁与原子保存**：候选模型提交后须完整通过安全 YAML、Schema、单位、接口与方程校验；校验失败的候选仅留在编辑态或临时隔离区，不分配正式编号、不进入建模选择器。
3. **版本与面板可见性**：项目内可用的模型选择器由当前草稿或所选项目版本声明的模型引用集合决定，历史版本恢复后不会显示其创建时刻之后新增的模型资产。

## 算法插件开发与运行约束

1. **两阶段分离**：算法插件包在 `src/` 下分别提供 `generate`（规范装配 → 求解输入与声明）与 `solve`（输入文件 → 声明结果），仍遵循标准 `Solver Bundle` 与 `ResultAdapter` 契约，不绕过通用计算链。
2. **离线纯 Python 交付**：第一版仅接收符合[算法插件包](formats/algorithm-plugin-package.md)布局的 Python ZIP 与离线依赖锁，拒绝原生二进制、动态链接库、Git/URL 依赖与安装脚本。
3. **严格沙箱假设**：
   - 运行环境无公网与内网访问权限、无数据库或对象存储凭证、无宿主机仓库目录；
   - 仅能读取 Manifest 声明的输入与独立临时工作目录，并受部署资源（CPU、内存、超时、进程数、文件大小）强制约束；
   - 相同输入、版本、依赖与种子须产生确定性结果。

## 共享、权限与生命周期

- **权限隔离**：未公开的草稿、上传包与校验明细仅对所有者可见；管理员拥有共享审核、停用或因安全风险阻断版本的权限；共享园地不暴露其他用户的项目与数据集。
- **停止共享与卸载**：停止共享仅阻止新增安装；用户卸载仅解除个人目录引用，仍被历史版本、任务快照或证据引用的对象不得物理删除，卸载前须提示引用影响。

## 外部交付自检清单

- **提交设备模型前**：确认通过 `1.0.0` Schema 校验、不含财务/精度/代码字段、具备稳定 ID 与许可证、并附带合法样例。
- **提交算法插件前**：确认 ZIP 目录与 Manifest 合规、依赖已完整锁定且支持离线构建、最小自检样例可在断网容器内确定性通过并正确校验输出 Schema。
