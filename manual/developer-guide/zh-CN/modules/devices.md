# 设备目录

> 代码边界：`backend/iesplan/devices/`；文件契约：[设备模型 YAML](../formats/device-model-yaml.md)

`devices` 拥有设备纯技术规格的解析、校验、目录发布与公开描述符（`DeviceDescriptor`）。它是前端设备面板、方程建模与项目装配共同依赖的设备事实源。

## 职责与边界

- **拥有**：稳定设备类型 ID、本地化显示名键、非时变 `properties`（单位与值域）、五类 `interfaces`（`in` / `out` / `bidirectional` / `predefined` / `blind`）、声明式 `equations`、设备 Provider 发现与目录快照原子发布。
- **不拥有**：项目设备实例 ID、画布布局、存量/新增身份、连接关系、项目数据源绑定、财务价格/成本、计算精度或求解器选项。
- **严格隔离**：设备文件与目录服务不得携带或回退到任何价格目录；调用方仅通过公开门面获取 `DeviceDescriptor`，不能读取物理文件路径。

## 校验门禁与发布机制

1. **统一入口**：内置设备目录、项目内新建/保存模型以及（`1.2.0` 目标的）本地模型库表单/YAML 编辑/导入，全部经过 `devices` 同一安全 YAML 解析、Schema 校验、单位/接口/方程验证与规范化入口。
2. **完整诊断输出**：校验尽量聚合同一阶段互不依赖的问题，返回带稳定顺序的 `Diagnostic` 集合（含错误码、字段路径、预期与实际值及 YAML 行列定位）。
3. **原子快照发布**：启动期发现全部候选设备并完成全部校验后一次性发布目录快照，任一设备校验失败或 ID 冲突均废弃候选集且不回退静态内置表。进程运行期目录快照保持稳定，不支持热加载。

## 可规划储能模型规则

内置电池等储能设备通过统一方程契约同时支持固定参数运行与容量/功率规划优化：

- 储能状态以明确能量单位表达，容量、额定功率、初始状态、SOC 上下限与充放电效率采用仿射关系，禁止将待规划容量放在分母中形成双线性约束；
- 零容量表示无可用储能（初始电量同步归零），不伪造 SOC 比值或额外添加未声明的终期闭合约束。

## 新增设备流程

1. 按[设备模型 YAML](../formats/device-model-yaml.md)编写纯技术定义并赋予带命名空间的稳定 ID（不含设备语义版本）。
2. 定义 `properties` 与五类 `interfaces`（仅 `predefined` 声明输入槽，不在设备文件中写项目数据来源；缺省接口规范化为 `blind`）。
3. 编写受限声明式 `equations` 并配套合法/非法 YAML 与 CSV 样例，验证目录接口、GUI 表单、装配校验与计算链路全线贯通，无需修改消费方设备类型表。
