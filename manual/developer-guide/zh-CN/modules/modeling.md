# 技术方程建模

> 代码边界：`backend/iesplan/modeling/`；相关格式：[设备模型 YAML](../formats/device-model-yaml.md)、[网络边界与系统方程](../formats/network-relations.md)

`modeling` 负责将设备模型与系统方程中的受限声明式表达式解析为统一的公共 AST，完成词法、语义与量纲校验，并转换为与求解器无关的声明式数学贡献（`ies.modeling.contribution@1.0.0`），供生成器消费。

## 职责与边界

- **拥有**：受限方程词法/语法解析（禁止 `eval` 或动态导入）、公共 AST、标识符/单位/有效区间/时间索引语义校验、设备级与系统级数学贡献规范化。
- **不拥有**：设备目录加载、项目图拓扑、规划目标/约束定义、财务参数与价格、求解器私有对象或进程执行。
- **无设备命令表**：所有设备共用同一套方程语法与转换契约，不存在按设备 ID 分发的私有命令注册表。

## 转换流水线

```text
DeviceDescriptor.equations / system_equations
  ↓ 安全词法与语法解析
规范公共 AST（ies.equation.ast@1.0.0）
  ↓ 标识符、单位与时间索引校验
设备 / 系统级数学贡献模板
  ↓ 绑定实例属性覆盖、接口引用与项目基线步长
不可变公共数学贡献（variables, relations, state transitions, initial_ast）
```

## 方程语言与贡献规则

1. **受限白名单语法**：仅支持数字常量（求值期换算为 SI）、括号、基础算术、比较符及本块声明的 `properties`、`interfaces`、内部 `variables` 与项目公开步长 `step_duration`。
2. **一阶时间索引**：仅允许 `[t]` 与 `[t-1]`；`[t-k]`（`k > 1`）在输入校验边界直接拒绝。首步 `t=0` 的 `[t-1]` 由状态变量的 `initial`（`property_ref` 或组合属性表达式 `initial_ast`）替代。
3. **规划接管保留关系**：当设备属性被规划变量接管时，数学贡献保留对原属性/规划变量的符号引用（包括 `valid_range` 中的 `property_ref` 与 `initial_ast`），由生成器依据统一能力降级，不提前代入模板默认值。
4. **系统方程复用同一内核**：装配中的 `system_equations` 复用本模块同一套公共 AST、量纲约简规则与数学贡献输出。

## 扩展与验证要求

扩展方程操作符或表达式能力前，须先确认是否可由现有语言组合实现；新增操作符必须明确类型、量纲、时间索引约束与复杂度边界，同步提供合法/非法/量纲冲突测试，并验证通用生成器无需按设备 ID 特判即可消费。
