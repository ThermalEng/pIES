# Roadmap

Roadmap 记录尚未交付的功能规划、版本顺序与退出标准。已通过验收并合入主线的功能统一记入[更新日志](README.md)并从本页移除。

## 版本规划约定

- `0.x`：正式发布前的契约收敛、工程验收与发布准备；
- `1.0.0`：小范围测试发布版本；
- `1.x`：测试期间的功能扩展与迭代（2.0 正式发布前自有契约标记固定为 `1.0.0`）；
- `2.0.0`：首个面向公众发布的版本（发布前制定兼容与迁移规则）。

## `1.1.0` 已交付基线

```text
第三方攻击面与公共边界（0.2–0.4）
  → 输入与装配契约（0.5–0.7）
  → 生成—执行—结果（0.8–0.10）
  → 应用编排与追溯切换（0.11–0.12）
  → GUI 与前端收敛（0.13–0.14）
  → 财务与预测计算收敛（0.14.5）
  → 全流程工程测试、正式打包与版本发布（1.0.0）
  → 求解器内建结构加速与大规模长周期求解优化（1.1.0）
```

*(注：`0.2.0`～`1.1.0` 已完成开发与工程验收，变更记录详见[更新日志](README.md)。)*

## `1.1.0` 后的 `1.x` 演进规划

### `1.1.5` — 临时计算容器流水线、统一插件契约与后端资源调度收敛

- 依据 `ADR-0016` 将原常驻 `io_worker` 与轻量异步任务调度收敛进 `backend`（编辑态快速校验继续保持同步），新增极薄白名单代理服务 `job_runner` 唯一受控持有宿主机 Docker Socket，常驻服务收敛为 `web`、`backend`、`job_runner`、`postgres`、`redis` 五个容器；
- 确立简洁且统一的 `ies.algorithm-plugin@1.0.0`（`plugin.yaml` + `/work/in → /work/out`）契约，覆盖 `predictor`、`generator`、`solver`、`evaluator` 与极简一体化 `algorithm` 五类种类、高级可选扩展段及内部循环算法专用接口；
- 将预测、组装器（HiGHS MILP）、求解器（HiGHS 1.7.2）、结果适配与后期财务计算/评价重构为由 `backend` 经 `job_runner` 按步骤拉起、算完即毁的断网临时计算容器，官方内置算法统一封装为不可变计算镜像接入；
- 退出标准：通过冷启动、阶段检查点恢复、取消/超时/OOM 回收、`1.1.0` 大规模规划基准与全量 Playwright 回归，无功能与性能退化。

### `1.2.0` — 开放模型与算法插件生态与 pIES Market

- 基于 `1.1.5` 统一插件契约与临时计算容器底座，实现第三方插件安装期经 `job_runner` 自动基于官方模板构建不可变计算镜像，并发布零依赖后端的独立开发者包 `pies-sdk`；
- 拆分独立公共市场仓库 `ThermalEng/pIES-Market` 与主程序 `ThermalEng/pIES` 解耦，公共市场不作为 pIES 本地计算的运行依赖；
- pIES 内置统一单页“模型与算法”市场入口，支持按制品/插件种类分类筛选及三态标识（`远端` / `本地（未安装）` / `本地（已安装）`），并由本地管理员切换**本地模式**（禁用远端市场与外网投稿，本地分享仅到管理员级别）与**联网模式**（全员可浏览、下载安装及邮箱验证投稿）；
- 建立基于命名空间（`ies.*` / `user.<public_namespace>.*` / `<publisher>.*`）的跨实例稳定标识、外部下载/导入边界 SHA-256 校验（内部持久化与快照不存储或重复复核）、无热加载不可变安装与 `CalcSnapshot` 提交冻结机制；
- 按切片推进落地：`M1` 公共契约与市场索引定稿 → `M2` 本地模型/插件管理、自动镜像构建与独立 `pies-sdk` → `M3` `pIES-Market` GitHub 仓库与静态 JSON 索引流水线 → `M4` 公共市场服务（邮箱验证码投稿、人工审核与独立下载入口）→ `M5` pIES 双模式市场集成与个人/企业双场景验收 → `M6` 精选工程参考设备模型、参考 Python 插件与开发示例。

### `1.3.0` — 规划—运行闭环与场景分析

- 典型工况容量规划与全年运行校核；
- 多场景项目计算基线与受控基线迁移；
- 敏感性计算、批量参数扫描、不确定性分析与多目标候选比较；
- 在基础财务指标上扩展 LCOE 等指标与独立资本金评价模型。

### `1.4.0` — MCP 接入与智能化数据准备

- 通过 MCP 向外部 AI 客户端开放项目操作能力，由专属登录页签发可撤销连接凭证，支持多端并发连接与草稿冲突提示；
- 提供待计算方案确认页面，AI 辅助生成候选输入后仍须由人工核对确认再创建冻结任务。

### `1.5.0` — Excel 数据标准化

- 借助外部 AI 通过 MCP 将非标准 Excel 数据转换为符合契约的标准数据集，保留转换说明与质量诊断，防止公式注入。

### `1.6.0` — 一键生成完整规划报告

- 基于冻结的项目快照与结构化计算证据生成可追溯的规划报告，保留版本来源与人工确认记录。

### `1.7.0` — 全量输入项说明与格式指引

- 所有填写项（表单输入框、选择器、数值及文本域）均提供统一的说明按钮；
- 支持鼠标长时间悬停（hover）或点击查看；
- 浮层清晰说明该项的业务内涵、计算口径、单位量纲、有效取值范围及填写格式规范；
- 具备完整的键盘可达性与无障碍（aria）支持，不影响原生表单输入与快捷操作。
