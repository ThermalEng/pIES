# Roadmap

Roadmap 记录尚未交付的功能规划、版本顺序与退出标准。已通过验收并合入主线的功能统一记入[更新日志](README.md)并从本页移除。

## 版本规划约定

- `0.x`：正式发布前的契约收敛、工程验收与发布准备；
- `1.0.0`：小范围测试发布版本；
- `1.x`：测试期间的功能扩展与迭代（2.0 正式发布前自有契约标记固定为 `1.0.0`）；
- `2.0.0`：首个面向公众发布的版本（发布前制定兼容与迁移规则）。

## `1.0.0` 已交付基线

```text
第三方攻击面与公共边界（0.2–0.4）
  → 输入与装配契约（0.5–0.7）
  → 生成—执行—结果（0.8–0.10）
  → 应用编排与追溯切换（0.11–0.12）
  → GUI 与前端收敛（0.13–0.14）
  → 财务与预测计算收敛（0.14.5）
  → 全流程工程测试、正式打包与版本发布（1.0.0）
```

*(注：`0.2.0`～`1.0.0` 已完成开发、工程全流程测试并正式发布为 `1.0.0`，变更记录详见[更新日志](README.md)。)*

## `1.0.0` 后的 `1.x` 演进规划

### `1.1.0` — 非传统求解器与大规模长周期求解加速

针对 25 年长周期、高分辨率（如 30 分钟共 `438,288` 步）多能互补规划算例中传统分支定界 MILP 求解器耗时过长的瓶颈，在保持公开架构边界与不可变证据链的前提下，引入非传统高效求解路线：

- **可插拔非传统求解引擎**：通过 `GeneratorProvider`、`SolverRuntime` 与 `ResultAdapterProvider` 公开契约接入一阶算子分裂（如 PDLP 风格加速算法）、结构分解协调（Benders / ADMM / 时序结构分解）、GPU/大规模并行求解器或启发式—精确混合加速算法；
- **可插拔前置启发式工程加速（`S0 -> S3` 渐进交付）**：采用可替换 `HeuristicProvider` 协议与单引擎首发策略，首期聚焦 `MILP（兼顾 LP）`——先建立 `highspy 1.7.2` 原生基线（`S0`），再打通 `CalculationConfig.options` 冻结、单调时钟截止点与 `setSolution` 接收/修复/失败/超时闭环测试（`S1`），随后落地 `Extreme-Aware` 代理缩域与结构感知 `Fix-and-Repair / Fix-and-Optimize` 默认引擎（`S2`），在同进程优先单次读模改界并经紧凑原模型约束增量核查后直接交付最佳已知工程可行方案（经验缩域统一发布 `feasible` 且原域全局界/Gap 置 `null`，在独立诊断保留子域状态，并在贴边、无解或迟迟无可行解时按余量尝试外扩）；最终以 Docker 同预算下的总耗时、峰值 RSS、首次可行解时间与相同时间预算下最佳可行目标值决定后续扩展（`S3`）；
- **数学口径与收敛透明性**：严格遵守实体设备物理守恒、分月分时电价、自然月最大需量与税后现金流口径，并在封存结果与摘要指标中如实标明所采用的非传统求解算法、收敛残差、相对间隙或边界校验结论；
- **零信任边界不退让**：新求解器继续在隔离运行环境中通过结构化 Solver Bundle 执行，不破坏模块自治、快照不可变性与财务一致性核对流程。

### `1.2.0` — 模型与算法、Provider SDK 与设备扩展

- 新增面向登录工程师的一级导航“模型与算法”，包含“模型库”“算法插件”与“共享园地”；
- 模型库支持表单、在线 YAML 与上传 YAML 统一生成不可变 `ies.device-model` 发布；
- 算法插件支持上传 `ies.algorithm-plugin` ZIP，在独立容器化隔离运行器中执行，确保 API/普通 Worker 不加载用户源码；
- 支持所有者申请共享、管理员审核及用户目录引用安装；
- 发布扩展 SDK 与验证工具，并逐步补充氢能、热/冷储能、风电、燃气内燃机、余热锅炉、吸收式制冷机及需求响应等设备与扩展财务规则。

### `1.3.0` — 规划—运行闭环与场景分析

- 典型工况容量规划与全年运行校核；
- 多场景项目计算基线与受控基线迁移；
- 敏感性计算、批量参数扫描、不确定性分析与多目标候选比较；
- 在基础财务指标上扩展 LCOE 等指标与独立资本金评价模型。

### `1.4.0` — MCP 接入与智能化数据准备

- 通过 MCP 向外部 AI 客户端开放项目操作能力，由专属登录页签发可撤销连接凭证，支持多端并发连接与草稿冲突提示；
- 提供待计算方案确认页面，AI 辅助生成候选输入后仍须由人工核对确认再创建冻结任务。

### `1.5.0` — Excel 数据标准化

- 借助外部 AI 通过 MCP 将非标准 Excel 数据转换为符合契约的标准数据集，保留转换说明与质量诊断，防止公式注入。

### `1.6.0` — 一键生成完整规划报告

- 基于冻结的项目快照与结构化计算证据生成可追溯的规划报告，保留版本来源与人工确认记录。

### `1.7.0` — 全量输入项说明与格式指引

- 所有填写项（表单输入框、选择器、数值及文本域）均提供统一的说明按钮；
- 支持鼠标长时间悬停（hover）或点击查看；
- 浮层清晰说明该项的业务内涵、计算口径、单位量纲、有效取值范围及填写格式规范；
- 具备完整的键盘可达性与无障碍（aria）支持，不影响原生表单输入与快捷操作。

## `2.0.0`

首个面向公众发布的版本。发布前完成公开边界冻结、兼容与数据迁移政策、回滚方案及公开验收。
